# Hafalan Hero

Aplikasi hafalan Al-Qur'an interaktif dengan kuis, murajaah, level, XP, dan statistik progres.

## Demo

🌐 https://websitewildan.my.id/projects/hafalan-hero/

## Fitur

* Quiz Sambung Ayat
* Quiz Arti Ayat
* Quiz Nomor Ayat
* Quiz Tebak Surah
* Murajaah Audio
* Sistem XP & Level
* Badge Prestasi
* Leaderboard Online
* Progressive Web App (PWA)

## Teknologi

* JavaScript
* PHP
* HTML
* CSS
* AlQuran Cloud API
